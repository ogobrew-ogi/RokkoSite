# Качване на нови снимки (Trips 06-11)

1. Качваш суровата снимка тук, именувана по номера на слота:
   `17.jpg`, `18.png`, `19.webp`... (приема `.jpg/.jpeg/.png/.webp/.tif/.tiff`, каквото е по-удобно).
2. От главната директория на проекта пускаш:
   ```
   npm run images
   ```
3. Скриптът автоматично изрязва/смалява и записва `images/<номер>.avif`,
   `images/<номер>.webp`, `images/<номер>.jpg` — готови за ползване.
4. Ако искаш да обновиш само няколко номера, подай ги като аргументи:
   ```
   npm run images -- 17 18 19
   ```

## Кой номер за какво (виж `tools/build-images.mjs` → `SLOTS`)

| Trip      | Банер (1600×900) | Снимка 1 (800×600) | Снимка 2 (800×600) |
|-----------|-------------------|----------------------|----------------------|
| Trip 06   | 17                | 18                   | 19                   |
| Trip 07   | 20                | 21                   | 22                   |
| Trip 08   | 23                | 24                   | 25                   |
| Trip 09   | 26                | 27                   | 28                   |
| Trip 10   | 29                | 30                   | 31                   |
| Trip 11   | 32                | 33                   | 34                   |

Докато номер още няма качена снимка, в `excursions.html`/`excursions-bg.html`
продължава да сочи към съществуващия SVG placeholder (`images/<номер>.svg`) —
нормално е и не се чупи нищо. Веднъж генерирани реалните `.avif/.webp/.jpg`,
трябва да обновим и HTML markup-а за тия секции (смяна на `<img src="...svg">`
и `data-bg="...svg"` към `<picture>`/base-path схемата, както е при trips 1-5) —
кажи кога са готови снимките и ще го направим наведно.
